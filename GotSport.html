Detect Coaching Conflicts Across Multiple Events

Automatically flag when coaches are assigned to overlapping teams in simultaneous competitions

Listen to audio version of this article

GotSport now detects coaching conflicts across multiple simultaneous events. Organizations running multiple leagues, flights, or tournaments can now automatically identify when a coach is assigned as primary coach to overlapping teams—preventing scheduling nightmares and ensuring compliance with competition rules.

This is especially newsworthy for leagues that have multiple events going on at the same time, where a coach might be listed with teams in more than one event on the same dates.

🎯 How It Works: The check scans each coach's primary teams across the chosen events and lists any date clashes in the Coach Conflicts box.

The Problem & Solution

Conflict checks used to work inside a single event, so clashes between flights needed manual review. Detection now spans events:

  • Multi-Event Comparison
    Pick several events that share dates and coach assignments are compared across them.
  • Smart Date Overlap Detection
    Events with no shared dates are skipped, so no false flags.
  • Clear Conflict Details
    Each clash shows match, time, venue and minutes of overlap.
  • Flexible Configuration
    A checkbox turns it on, then you choose the events to include.

How to Use It

Setup takes six quick steps:

  1. Open Scheduling > Match Chart in one of your events
  2. Select the Coaching Conflicts button
  3. Tick “Compare with other events”
  4. In the multi-select dropdown, pick the events to include
  5. Press “Apply / Refresh”
  6. Read the results in the Coach Conflicts box.
How to Identify How Many Coach Conflicts are in your Event Schedule.
💡 Pro Tip: Only events from the same organization with overlapping dates can be compared.

Get Started Today

It is live now in the Scheduling module and needs no setup; just switch it on when needed.
